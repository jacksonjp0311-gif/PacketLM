# PacketLM

A language model assembled from routed binary weight packets instead of one dense slab.

Bitwork geometry core: 4096-bit patterns, Hamming-space nearest neighbor, temporal routing, eval-gated promotion. CPU-runner trainability. Local-first. Evidence-gated. No auto-promotion.

## Interlink with NOMAD

PacketLM interconnects with [NOMAD](https://github.com/jacksonjp0311-gif/NOMAD) via the symbiotic protocol.

- Marks presence through interlink inspect.
- Offers certified packets with receipts.
- Receives geometry handover.
- Never writes the NOMAD field directly. Body remains authority.

See [docs/INTERLINK.md](docs/INTERLINK.md) for the handshake.
