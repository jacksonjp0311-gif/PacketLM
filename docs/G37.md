# G37 — Geometric integrity

Audit findings accepted.

## Fixed

- Router now calls `p.score(residual)`, which is `2|q ∩ p| - |p|`. Larger packets are no longer favored.
- Sentence hash features now use 16-bit slices, so they land across all 4096 bits, not the first 256.

## Still open

- Holdout in tiny.py is contaminated. Training pairs are built before the holdout is cut.
- Attention matrices are not trained or saved.
- Speak counts a surplus fallback as a hit. Retrieval and generation must be scored apart.
- Inference hops are seeded. That is traversal, not deduction.
- Two geometries exist: Bitwork binary score, and token-set overlap times strength. They must become one.

## Claim

The field can route and hold. It has not been given a fair test of its own geometry. These fixes start that test. Not a mind.
