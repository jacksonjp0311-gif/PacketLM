# G37 — Geometric integrity

## Fixed

- Router calls `p.score(residual)` = `2|q ∩ p| - |p|`.
- Sentence hash features spread across all 4096 bits.
- Holdout windows are cut before training pairs are built.
- Speak reports `retrieved` and `generated` separately.
- Role binding: subject, relation, and object are rotated, then XOR-bound. Alice helps Bob is not Bob helps Alice.

## Still open

- Attention matrices are not trained or saved.
- Field walk still uses token-set overlap, not the Bitwork score.
- Inference hops are seeded.
- Roles are assigned, not learned.
