# G37 — Geometric integrity

## Fixed

- Router calls `p.score(residual)` = `2|q ∩ p| - |p|`.
- Sentence hash features spread across all 4096 bits.
- Holdout windows are cut before training pairs are built.
- Speak reports `retrieved` and `generated` separately. A surplus fallback is not a generation hit.

## Still open

- Attention matrices are not trained or saved.
- Two geometries: Bitwork binary score, and token-set overlap times strength.
- Inference hops are seeded. Traversal, not deduction.
- Role binding is not implemented. Overlap cannot tell who did what.
