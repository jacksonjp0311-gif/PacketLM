# G46-U: unrelated curriculum (pre-registered before any G46 result was read)

This follows the learning-amortization feedback (curricula: compositional vs unrelated).
G46 is the compositional curriculum. G46-U runs the same frozen engine, teacher, budgets
(2 examples, ≤4 investigations, `--deepen=5`) and cost accounting on 24 tasks. Each task
lives in a fresh family: new relation names, new entities, 4 layers of 8, and a random
program shape from {ab, ba, abc, cab, bc, ca, aa, cb}. Nothing earlier can be reused.
The family-end steps (corrections and the phase-B conditions) do not apply; transfer and
retention calls still run for the persistent arms and are reported as maintenance.

**Arms:** C (continual), B (empty-memory), P (primitive-only); seeds 11, 22, 33.

**Prediction:**
- On an unrelated curriculum, retained knowledge cannot reduce search. It still costs load,
  validation, scanning and storage on every call.
- Expectation: `A_24(C‖B) ≤ 0` in every seed (the utility problem), and C's library is
  used in 0 tasks, i.e. 0 library uses.
- If `A_24 > 0`, something other than reuse is making C cheaper, and it must be explained
  before any amortization claim is made from G46.

Costs are exported with `benchmarks/la_export.py` and read with the pinned instrument.

## Results (same frozen engine, unchanged; run 21:40–21:42 EST)

Evidence in `docs/evidence/g46u/`.

- All arms acquire 24/24 tasks, with sealed accuracy 96/96 in every seed.
- C's library is used in **0** tasks.
- Task CPU: C 12.6 / 11.9 / 11.6 s; B 0.51 / 0.48 / 0.51 s; P 12.0 / 11.7 / 11.5 s.
- Pinned instrument:
  - `A_24(C‖B)` = **−23.1 [−24.0, −21.5]**; with maintenance, −81.4;
  - `A_24(C‖P)` = −0.030 [−0.057, −0.011];
  - no censoring.
- **Prediction confirmed (`A ≤ 0`, 0 library uses).** On an unrelated curriculum, retained
  memory is pure overhead.
- C and P cost the same, so the overhead comes from retained *knowledge* (entities and facts
  scanned on every call), not from the library.
- Combined with G46 (compositional, `A^reuse` = +0.225 but `A(C‖B)` = −7.0): in the current
  engine, the per-call cost of everything retained dominates whatever composition saves.
