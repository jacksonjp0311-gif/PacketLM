## Acceptance criteria

Each item is a named check in `packetlm/g44_test.py`. Each must be able to fail.

1. **One engine.** `packetlm/engine.py` holds memory, constructions,
   geometric execution, acquisition, discovery, library and persistence.
   It reuses `field` (bind/ask/decode), `roles` (induce/select),
   `geom` (rows_from/compose/bits) and `system.invalidate`.
   Duplicated `choose`/`express` in `chat` and `geom` route through it.
2. **Provenance.** Every stored fact records its source and turn; a derived
   fact records its premises and the program that made it.
3. **Correction.** Correcting a premise replaces it and removes facts derived
   from it, recursively. An unrelated fact stays.
4. **Retraction.** Retracting a fact removes it and its dependents; the
   question then abstains. Retraction is logged, not silent.
5. **Ambiguity.** Two live values for one subject and relation abstain with
   `ambiguous`; they are not resolved by order.
6. **Constructions.** Word order is induced from two examples (`roles.induce`);
   reading and speaking use the induced construction; an unknown word abstains.
7. **Binary execution.** Programs run on bit-row matrices (`geom.compose`).
   Control: on every acquired program and subject in the tests, the bitwise
   result equals a step-by-step walk with `field.ask` over the bound packets.
8. **Acquisition.** A program is found from accumulated observations only.
   Unique supported → acquired. Several supported → kept as live hypotheses.
9. **Three-way judgement.** Each hypothesis is supported, contradicted or
   undetermined. A missing fact is undetermined, never contradicted.
   Control: a hypothesis with no prediction survives a real answer.
10. **Active discovery.** The engine picks its own questions; the hidden target
    lives only in a test oracle and never enters engine state. Several seeds,
    several targets.
11. **Library reuse.** An acquired program is a capability and can be a step in
    a later search. Control: the same later search with the library disabled
    finds nothing at the same depth.
12. **Persistence.** Save is atomic (temp file, fsync, replace), keeps the prior
    generation as a backup, and carries a schema version and checksum. Load
    validates. A corrupt primary falls back to the backup **and says so** in
    the load report. Both corrupt raises; it never returns empty state.
13. **Fresh process.** Teach in one Python process, ask in a second, correct in
    a third, verify in a fourth. Each is a new interpreter (`subprocess`).
14. **Retain.** All 8 workflow modules still pass with the same check names.

## Claim boundary

Symbolic and bitwise. No transformer, no LLM runtime. Not a mind.
