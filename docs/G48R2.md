# G48R2: G48 replication after the verification of 82dd0a2 (pre-registered)

This was written and committed before `python3 benchmarks/g48.py --seeds 511,...,517 --out g48r2`
ran. Dev seeds 998 and 999 were run with the final engine and harness, and their receipt is in
`docs/evidence/g48r2/dev/`.

## What changed since G48 and G48R, and why

| change | reason |
|---|---|
| Programs-mode investigate scores only the observations' component, in name order | G48 H6 (order) and G48R H6 / verification N1 (set). Tested by `prog_question_pool_same_set_under_retention`. |
| Open-world scan to MAX_SIZE = 5, not to the candidate's size | Verification N2: aligns with the base engine's full-budget rule (audit P0). Tested by `prog_filter_full_horizon_blocks` and the mutation `prog_scan_short_horizon`. |
| T4 examples are never sealed items; a new harness check `no_example_is_evaluated` | Verification N3 |
| The receipt records an engine-only hash | Verification L4 |

## Protocol

Identical to G48 (docs/G48.md) apart from the changes above. Arms P, X, S and A; 2 rounds; the
same world generators, teacher, budgets and metrics. **Seeds 511–517** (S = 7), never run
before.

## Thresholds (all must hold)

**From G48, word for word:**
- H1: P per class ≥ 0.95.
- H2: P T1 at depth ≥ 3 ≥ 0.95.
- H3: P wrong-qualified = 0.
- H4: X on T1–T3 ≤ 0.5.
- H5: S ≤ 0.10.
- H6: A's replies byte-identical to P's on every seed.
- Source unchanged.

**New:** `no_example_is_evaluated`.

**Stated in advance about H3:** under the full horizon, the dev seeds gave **0 qualified
tasks**. Every acquisition was provisional, because longer alternatives such as `is:K:T|…` are
defined where the candidate is not. If that holds here, H3 passes vacuously and is reported as
having nothing to test. It is not claimed as evidence. Moving acquisitions toward qualification
is the separate protocol-extension experiment (docs/PX.md, registered after this run).

## Dev (seeds 998, 999; final engine `e30c08437fe9…`)

- P: 0 qualified tasks, and every task provisional.
