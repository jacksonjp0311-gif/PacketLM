# G55: option 3, an observation-independent guard budget under `complete`

Steering at 02:17 (America/New_York, 2026-11-27): "pre-register option 3 if time remains" (a guard
budget independent of observations, with its cost measured).

## 1. Problem (from G52)

- Under `complete`, sound qualification in programs mode needs the guard space to be every (Q, T)
  pair on the acquisition component plus one absent pair (H1 of b2bb9b8). If that exceeds
  MAX_GUARDS = 8, qualification is capped at provisional (`scan.guard_gap`).
- In G52 the F arm's components carried 25–69 pairs (median 38.5), so F qualified **0/56** tasks
  (FC2 failed, as predicted).

## 2. Mechanism: `--closed-guards=N`

- Under a `complete` observation the full component pair space is used whenever it has at most N
  pairs; above N the cap applies as before. N is a constant: it does not depend on the
  observations, so the H1 soundness argument is unchanged. N = 8 (the default) is the G52 rule.
- A larger space is scanned by the same exact scan (`programs.Exact`, EXACT_BUDGET combinations).
  If the scan does not complete, the status stays provisional, as before.
- **Tests:** check `g55_budget_covers_component` (the H1 gap world: with N = 16 the gap is 0 and
  the status follows the completed scan; there it finds a blocker, so it is provisional for a
  real reason). Mutation `g55_budget_ignored`.

**Decision rules (fixed now), for N = 32:**

| rule | what is claimed, and when |
|---|---|
| **Q** | The budget raises qualification only if F_N qualifies more tasks than F8 in total and F_N has 0 wrong-qualified sealed answers |
| **C** | The cost is acceptable only if the median per-seed ratio of whole-process CPU F_N / F8 is ≤ 2.0 |
| **Adopt** | N is recommended as the default only if Q and C hold and the soundness probe at N = 32 shows 0 wrong-qualified answers. Changing the default is a separate step, not done in this chunk |

**Guards (run validity):** 0 wrong-qualified in F8 and F32; every false `complete` statement of

- **What this means.** With N = 32 the full space is scanned and completes. The completed scan
  then finds many genuine alternative programs (≥ 16 per scan) that fit every observation. So the
  provisional status under F32 is the **sound** outcome, not a cap artefact. G52's 0/56 was
  over-determined: lifting the budget turns "capped" into "really ambiguous".
- **Cost.** Each covered scan grows by about 50–100× in combinations (2.7k → 150k–291k).
- **Adversarial dev** (budget 72, 60 cases, seed 9201, fullspace): 42 cases, 42 qualified,
  0 wrong-qualified. Budget 8: 33 qualified, 0 wrong.

**Predictions (stated from dev, before the registered run):**
- **Q fails.** F32 qualifies no more than F8; both are expected to be 0 or near 0.
- **C likely fails.** The F32/F8 CPU ratio is expected to be > 2, because the covered scans are
  50–100× larger.
- **Adopt: no.** Soundness is expected to hold (0 wrong-qualified).
- **Runtime.** The registered run is estimated at more than 1 h on this box, dominated by L32. It is
  registered here, and whether it runs is recorded in the ledger.
