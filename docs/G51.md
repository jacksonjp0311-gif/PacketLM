## 6. Decision rules (fixed now)

- **L1 (learning-to-learn, compositional):** claimed for arm X ∈ {C, Q} only if A(X+maint ‖ B)
  has a 95% seed-bootstrap interval with lower bound **> 0**. Otherwise **no claim**, and the
  estimate is reported as measured.
- **L2 (reuse, compositional):** a reuse advantage is claimed only if the lower bound of the
  95% interval of A(C+maint ‖ P+maint) is > 0.
- **L3 (utility problem, unrelated):**
  - The prediction, from G46-U and ARET, is A(C+maint ‖ B) < 0.
  - If the interval's upper bound is < 0, we state that the persistent learner costs more than
    the empty-state learner on unrelated tasks (the utility problem persists).
  - If the lower bound is > 0, we state that it does not.
  - Otherwise the result is inconclusive.
- **L4 (qualified-only vs all):** A(Q+maint ‖ C+maint) is reported with its interval. No
  direction is predicted.
- **Guards (run validity):**
  - C and Q have 0 wrong-qualified sealed answers on both curricula;
  - the instrument is pinned and unmodified;
  - every report ran;
  - source unchanged.

| rule | outcome |
|---|---|
| **L1** (learning-to-learn, compositional) | **No claim.** For both C and Q the interval is entirely **below 0**: the persistent learner whose qualified capabilities feed later acquisition costs 1 − A = 3.87× the empty-state learner's whole-process CPU over the sequence (215.8 s / 55.7 s). *Corrected after verify-cdb4828 G1: this text first said "e^2.9 ≈ 18×", a misreading of the instrument's A_n = 1 − C_cont/C_base; the number and the decision are unchanged* |
| **L2** (reuse) | **No claim.** A(C+maint ‖ P+maint) < 0: reusing capabilities costs more than primitive-only persistence (1 − A = 1.77×; *corrected after verify-cdb4828 G1, first written "≈ 2.2×"*) |
| **L3** (utility problem, unrelated) | **Stated:** the interval's upper bound, −4.86, is < 0. ### What this shows

- **Qualified capabilities do feed later acquisition.** On the compositional curriculum, 144
  tasks were acquired through a qualified library capability, and every C and Q task was
  solved (252/252).
- **But on whole-process CPU they do not make acquisition cheaper than starting empty, and they
  do not make it cheaper than persistence without a library.**
- **Why the empty-state reference wins:**
  - It searches a small state per task.
  - The persistent learner's per-task cost grows with the accumulated state: the trend of the
    per-task log ratio is −0.049 per task.
  - The library adds candidate steps, which multiplies the search: A(C ‖ P) = −0.88 (1.88×).
- *Note (verify-cdb4828 Info):* contrasts near zero, such as Q ‖ C on either curriculum, are within the CPU measurement noise. On the unrelated curriculum the instrument reports a break-even n of 14 for Q ‖ C; with an interval containing 0 this is not a finding.
- **What the next design needs:** to make amortization possible, the cost of offering a
  capability has to be bounded, for example by relevance-gated library retrieval. That is a new
  design and needs its own pre-registration.
