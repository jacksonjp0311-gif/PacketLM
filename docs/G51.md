measurement where qualified capabilities from earlier tasks feed later acquisition
(compositional and unrelated curricula, whole-process CPU with maintenance, ≥ 7 seeds, pinned
instrument at 70297af), against empty-state, frozen and primitive-only controls."

## 1. Instrument and cost (unchanged rules, docs/LA_EXPORT.md)

- **Instrument:** `learning-amortization` at **70297af**, unmodified, from
  `/workspace/vendor/learning-amortization` via `PYTHONPATH`. The receipt records the
  checkout's HEAD and a clean working-tree check.
- **Report:** `python -m amortization CSV --cont X --base Y --n N --bootstrap 5000`, printed
  verbatim into the receipt.
- **Cost:** whole-process CPU (`cpu_total_s`: getrusage user+sys, including interpreter
  startup), exported by `benchmarks/la_export.py` with `res = cpu_total_s`. Maintenance (the
  family-end correction, transfer and retention calls) is charged in the `<arm>+maint`
  variants. Primary contrasts use `+maint` for every persistent arm.
- **Censoring:** a task is censored unless every sealed reply on it is correct. The instrument's
  direction notes apply.

## 2. Teacher (every arm)

The G50 `complete` teacher:
- `--answers` with the PX statements;

This is the condition under which capabilities **qualify** (G50 dev: 69/71 G46 tasks).

## 3. Arms

| arm | flags | meaning |
|---|---|---|
| C | `--answers` | persistent; the library offers qualified **and** provisional capabilities (as G46 C) |
| Q | `--answers --qualified-library` | persistent; the library offers **only qualified** capabilities. This is the "qualified capabilities feed later acquisition" arm |
| B | `--answers --no-library` | empty state per task: the reference learner |
| P | `--answers --no-library` | persistent, primitive-only: no capability reuse |
| F | `--answers` | frozen after phase A: G46's F; phase-B tasks are not taught. Compositional curriculum only, since on G46-U it would equal C |

**New engine flag `--qualified-library`.**
- `primitives()` offers a capability as a library step only if its current version is
  `qualified`. Nothing else changes.
- Covered by check `g51_qualified_library_offers_only_qualified` and a mutation.

- **Unrelated:** G46-U worlds, 24 tasks, every task in a fresh relation family, so nothing can

## 6. Decision rules (fixed now)

- **L1 (learning-to-learn, compositional):** claimed for arm X ∈ {C, Q} only if A(X+maint ‖ B)
  has a 95% seed-bootstrap interval with lower bound **> 0**. Otherwise **no claim**, and the
  estimate is reported as measured.
- **L2 (reuse, compositional):** a reuse advantage is claimed only if the lower bound of the
  95% interval of A(C+maint ‖ P+maint) is > 0.
- **L3 (utility problem, unrelated):**
  - The prediction, from G46-U and ARET, is A(C+maint ‖ B) < 0.
  - If the interval's upper bound is < 0, we state that the persistent learner costs more than
    the empty-state learner on unrelated tasks (the utility problem persists).
  - If the lower bound is > 0, we state that it does not.
  - Otherwise the result is inconclusive.
- **L4 (qualified-only vs all):** A(Q+maint ‖ C+maint) is reported with its interval. No
  direction is predicted.
- **Guards (run validity):**
  - C and Q have 0 wrong-qualified sealed answers on both curricula;
  - the instrument is pinned and unmodified;
  - every report ran;
  - source unchanged.

**Reported alongside:**
- per seed and arm: solved tasks, qualified tasks, tasks using the library, and those that use
  it while qualified;
- G46 thresholds 1–6 for the persistent arms;
- `cpu_total_all_s`;
- censoring counts;
- the instrument's A_n curve and break-even point, verbatim.

## 7. Dev run (seeds 901–904, before registration; not evidence)

- **Run:** `python3 benchmarks/g51.py --dev --comp-seeds 901,902 --unrel-seeds 903,904`
- **Purpose:** check that the pipeline runs. It is not used to set any rule. All four guards held.
- **What it produces:**
  - Each instrument report runs and prints A_n with an interval.
  - The `+maint` variants exist for C, Q, P and F. B has no maintenance.
- **What it shows (S = 2, so only indicative):**
  - A(C+maint ‖ B) is about −3.0 on the compositional curriculum and −4.8 on the unrelated one.
  - A(C ‖ P) is −0.89 on the compositional curriculum.
  - The persistent learner pays a large cost to search and maintain a growing state and
    library. With the empty-state reference that cost is absent, so the reference is much cheaper
    per task.
  - On the compositional curriculum C solves 35/36 and 36/36 tasks, qualifies 35 and 34, and it
    uses the library in 20 and 21 tasks.
- **Prediction:** L1 will probably fail. The rules stay as written above; they were fixed before
  this dev run.
