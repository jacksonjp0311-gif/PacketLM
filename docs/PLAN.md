# PacketLM plan

## Goal
A field of nodes you can query. Bitwork-style overlap routes the query. A node answers. A change is kept only if a sealed score rises.

## Shape
1. Nodes are the center. Language, recall, probe.
2. A query becomes a token set. Overlap picks the node. Receipt the route.
3. Stories are the language node's data, not the whole system.
4. The tiny model is the language node's learner.
5. Self-edit keeps a change only if probe hits rise.
6. Weights persist when a score does not fall.

## Claim
Not an intelligence. A routable field that can grow under measurement.
