## 1. The statement `complete X` (designed, stated precisely)

**Meaning.** The teacher asserts that every fact whose subject is reachable from X along told
facts is told. The scope is that closure, computed when the statement is made and stored.

**Why it licenses a closed-world judgment at X, and only at X.**
- Every token a program runs from X reads only facts of entities reachable from X:
  - `rel:` and `cap:` steps follow outgoing facts, and capabilities are programs over the same
    facts;
  - guards test facts of the current node.
- So with the closure complete, the program's output **at X** is final. It cannot gain or lose
  a value when more facts arrive.

**Judgment** (`judge_closed`), for an observation at a `complete` subject X:

| answer | the prediction set must be | otherwise |
|---|---|---|
| a value `v` | exactly `{v}` | contradicted, including when the prediction is empty or has several values |
| `!none` | empty | contradicted |
| `!several` | two or more values | contradicted |

- "Not executable" (a dependency) stays undetermined.
- Elsewhere the open-world `judge_set` is unchanged.
- The judgment applies wherever observations are judged: `evaluate`, review, the base scan,
  `Inducer.search`/`marks`, and `Exact`.

**What it can and cannot do.**
- It refutes alternatives that are **less defined** (or several-valued) at an observed
  `complete` subject. In the open world these survive as "undetermined" and block.
- It says nothing about unobserved entities, and adds no values or facts.

**Defeasible.**
- A told fact **added or removed** whose subject is in a stored closure falsifies the statement.
  - The statement is retracted and logged in `complete_log` (stated turn, retracted turn,
    reason).
  - Every capability observed at X is re-acquired under the open-world judgment.
- Derived facts don't count. `cap:` conclusions don't count.

**Refused under adaptive retention** (archiving would hide closure facts).

## 3. Arms

All arms use programs mode, the exact scan, G48-style worlds, 2 rounds, and new seeds
**531–537**.

| arm | flags | teacher |
|---|---|---|
| P | `--programs` | values; no single value → withheld |
| R | `--programs --answers` | PX: `!none`/`!several` for non-sealed no-value items |
| F | as R | R + `complete s` for **every subject it answers**: examples and answered questions. Honest: every closure is fully told |
| N | as R | R + as many `complete e` statements about entities **not** asked at the time. Scope control |
| L | as R | **lying / incomplete-facts teacher**: for each example subject of T1, T2 and T3, one told fact inside its closure is withheld (seeded draw, shared with L0), yet F's `complete` statements are made. After a first evaluation of the sealed items (the "window"), the withheld facts are told, and the sealed items are evaluated again |
| L0 | as R | L's withheld facts and reveal, **no** `complete` statements. Open-world baseline for L |

T4 reuses the T1 world, which is already told in full, so there is no withholding there.
